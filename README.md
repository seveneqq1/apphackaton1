# ErgoNeck — прототип напоминания о положении головы

ErgoNeck показывает поток с камеры ноутбука, отслеживает закреплённую на очках ArUco-метку и напоминает пользователю поднять экран, если наклон головы вперёд остаётся больше 15° в течение 3 секунд.

Это локальный прототип: сервер, аккаунт, сайт и приложение на телефоне не нужны.

## Быстрый запуск

В Terminal выполните:

```bash
cd ~/Desktop/app
./run.sh
```

Первый запуск создаст локальное окружение `.venv` и установит зависимости. Для печати метки один раз выполните:

```bash
source .venv/bin/activate
python generate_marker.py --id 0 --output marker_0.png
```

На macOS подтвердите Python доступ к камере, если система спросит. `Q` завершает программу, `C` запускает двухсекундную калибровку исходной позы.

Если у нужной камеры другой индекс, попробуйте `./run.sh --camera 1`.

## Подготовка метки

1. Запустите `python generate_marker.py`. Файл `marker_0.png` готов к печати.
2. Напечатайте его так, чтобы сторона **внутреннего чёрно-белого квадрата** была примерно 45 мм (белое поле не измеряйте).
3. Приклейте лист на жёсткую плоскую подложку и закрепите на оправе. Метка не должна изгибаться или двигаться относительно очков.
4. Если вы меняете размер квадрата, передайте новый размер в миллиметрах: `python main.py --marker-size-mm 50`.

## Калибровка камеры (нужно для измерения углов)

Без файла калибровки программа работает в тестовом режиме с приближёнными параметрами объектива. Для демонстрации с измерением углов выполните один раз для этой камеры и её разрешения:

```bash
./.venv/bin/python calibrate_camera.py --corners-x 9 --corners-y 6 --square-mm 25
```

`corners-x` и `corners-y` — количество **внутренних** углов на вашей шахматной доске, а `square-mm` — реальная сторона её клетки. Держите доску резко в 15–25 разных положениях и нажимайте `Space` для каждого кадра. Файл `camera_calibration.npz` сохранится рядом с программой и автоматически загрузится при следующем запуске.

## Правила предупреждения

- `C`: программа 2 секунды собирает устойчивые измерения и запоминает удобную прямую позу.
- Наклон вперёд > 15° непрерывно 3 секунды: крупное красное предупреждение и короткий системный сигнал.
- Возврат до 10° на 2 секунды: предупреждение снимается. Разные пороги предотвращают мигание около границы.
- Метка пропала: показывается «Метка не видна», угол не подставляется, а отсчёт превышения сбрасывается.
- Последние пять корректных углов сглаживаются медианой.

Заполните [VALIDATION.md](VALIDATION.md) перед защитой: в нём есть таблица проверки углов и короткий чек-лист репетиции.

## Важная проверка перед показом

Наденьте очки и выполните калибровку. При опускании головы значение «Наклон вперёд» должно расти. Если оно становится отрицательным, переверните знак:

```bash
./run.sh --forward-sign -1
```

Проверьте показания на подставке с транспортиром при 0°, 10°, 20° и 30° и запишите реальную погрешность. Не заявляйте точность, которую вы не измерили.

## Ограничения прототипа

- Камера должна видеть всю метку при хорошем освещении.
- Ориентация измеряется относительно позы, сохранённой в текущей сессии.
- Крепление метки и позиция камеры должны оставаться неподвижными после калибровки.
