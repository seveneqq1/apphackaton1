# ErgoNeck — напоминание о положении головы по четырём точкам

ErgoNeck показывает поток с камеры ноутбука и отслеживает четыре чёрные круглые точки на оправе. По положению их центров программа восстанавливает наклон очков относительно камеры и напоминает поднять экран, если наклон головы вперёд остаётся больше 15° в течение 3 секунд.

Это локальный прототип: сервер, аккаунт, сайт и приложение на телефоне не нужны.

## Быстрый запуск

В Terminal выполните:

```bash
cd ~/Desktop/app
./run.sh
```

Первый запуск создаст локальное окружение `.venv` и установит зависимости. На macOS подтвердите Python доступ к камере, если система спросит. `Q` завершает программу, `C` запускает двухсекундную калибровку исходной позы.

Если у нужной камеры другой индекс, попробуйте `./run.sh --camera 1`.

## Что закрепить на очках

Нужны **четыре одинаковые матовые чёрные круглые точки**: верхняя левая, верхняя правая, нижняя правая и нижняя левая на фронтальной части оправы. Программа рисует зелёную рамку и номера `1–4` вокруг найденных центров.

1. Вырежьте четыре круга диаметром 10–12 мм из чёрной изоленты, винила или бумаги.
2. Приклейте каждый круг в центр маленького белого квадратика из плотной бумаги или пластика размером примерно 18×18 мм. Белая подложка особенно важна для тёмной оправы.
3. Жёстко закрепите эти площадки по четырём внешним углам **передней плоскости** очков. Точки должны быть примерно в одной плоскости, не на загнутых дужках.
4. Расстояние между центрами верхних левой и правой точек измерьте линейкой; затем измерьте расстояние между центрами верхней и нижней точки с одной стороны. Для обычной взрослой оправы это часто примерно 135 мм и 45 мм.
5. Если размеры отличаются от стандартных, передайте реальные значения при запуске:

```bash
./run.sh --dots-width-mm 135 --dots-height-mm 45
```

Точки должны быть хорошо освещены и отделены друг от друга. Не используйте блестящие ручечные точки: блики и тени делают их нестабильными. Если зелёная рамка не появляется, уберите тёмные круглые предметы из кадра, добавьте свет или попробуйте сделать точки больше.

## Калибровка камеры (для точных градусов)

Без файла калибровки программа работает в тестовом режиме с приближёнными параметрами объектива. Для демонстрации с измерением углов выполните один раз для этой камеры и разрешения:

```bash
./.venv/bin/python calibrate_camera.py --corners-x 9 --corners-y 6 --square-mm 25
```

`corners-x` и `corners-y` — количество **внутренних** углов на вашей шахматной доске, а `square-mm` — реальная сторона её клетки. Держите доску резко в 15–25 разных положениях и нажимайте `Space` для каждого кадра. Файл `camera_calibration.npz` автоматически загрузится при следующем запуске.

## Правила предупреждения

- `C`: программа 2 секунды собирает устойчивые измерения и запоминает удобную прямую позу.
- Наклон вперёд > 15° непрерывно 3 секунды: крупное красное предупреждение и короткий системный сигнал.
- Возврат до 10° на 2 секунды: предупреждение снимается. Разные пороги предотвращают мигание около границы.
- Хотя бы одна точка пропала: показывается «Точки не видны», угол — прочерк, а отсчёт превышения и буфер сглаживания сбрасываются.
- Последние пять корректных углов сглаживаются медианой.

Заполните [VALIDATION.md](VALIDATION.md) перед защитой: в нём есть таблица проверки углов и короткий чек-лист репетиции.

## Важная проверка перед показом

Наденьте очки и выполните калибровку. При опускании головы значение «Наклон вперёд» должно расти. Если оно становится отрицательным, переверните знак:

```bash
./run.sh --forward-sign -1
```

Проверьте показания на подставке с транспортиром при 0°, 10°, 20° и 30° и запишите реальную погрешность. Не заявляйте точность, которую вы не измерили.

## Ограничения прототипа

- Камера должна одновременно видеть все четыре точки при хорошем освещении.
- Все центры точек должны лежать примерно в одной передней плоскости оправы.
- Ориентация измеряется относительно позы, сохранённой в текущей сессии.
- Крепление точек и позиция камеры должны оставаться неподвижными после калибровки.
