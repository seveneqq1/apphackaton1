# Проверка измерений ErgoNeck

Проведите тест с очками на неподвижной подставке и транспортиром. Камера, расстояние до неё и крепление метки должны оставаться теми же, что и на демонстрации.

| --- | --- | --- | --- | --- | --- |
| 0° |  |  |  |  |  |
| 10° |  |  |  |  |  |
| 20° |  |  |  |  |  |
| 30° |  |  |  |  |  |

`Средняя разница` — модуль разности между заданным углом и средним показанием программы. Не указывайте точность в защите, пока эта таблица не заполнена.

## Чек-лист демонстрации

- [ ] Камера видит метку и зелёная рамка удерживается при небольших движениях.
- [ ] Нажать `C`, смотреть прямо и дождаться «Калибровка завершена».
- [ ] Коротко наклонить голову больше 15°: красного предупреждения нет.
- [ ] Удерживать наклон больше 15°: через 3 секунды появляется красное предупреждение и короткий звук.
- [ ] Вернуться ниже 10°: через 2 секунды предупреждение исчезает.
- [ ] Закрыть метку рукой: отображаются «Метки не видны», а угол — прочерк.
- [ ] Повернуть голову в сторону: это не должно восприниматься как наклон вперёд больше порога.
